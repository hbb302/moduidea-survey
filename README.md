# presurvey · 「모두의 아이디어」 TOP 100 Summit 사전 설문

> 1차 심사 통과 100인(기술 40 · 정책 60) 대상 워크숍 사전 설문지.
> 단일 HTML + Google Apps Script + Google 스프레드시트로 동작.

---

## 폴더 구성

```
presurvey/
├── index.html                              ─ 설문 페이지 (단일 파일)
├── apps_script_backend.gs                   ─ Google Apps Script 백엔드 코드
├── 사전설문_배포가이드_2026-05-28.txt        ─ 비개발자용 5단계 상세 배포 가이드
├── 빠른배포_1페이지_체크리스트.txt           ─ 압축본 (A4 한 장 / 약 20분)
├── 발송_안내문_기술분야.txt                  ─ 기술 분야 40명 발송 템플릿 (이메일·문자)
├── 발송_안내문_정책분야.txt                  ─ 정책 분야 60명 발송 템플릿 (이메일·문자)
├── README.md                                ─ 본 파일
└── _audit/                                  ─ 자가검증 자료 (운영자 검증 시 참조)
    ├── 피드백반영_검증리포트.txt              ─ 피드백 7건 적용 증거 (자동 생성)
    ├── 문항일치_검증리포트.txt                ─ docx 원문 ↔ HTML 매칭 결과 (자동 생성)
    ├── 원본_문항_추출.txt                    ─ docx 원문 단락 추출본
    └── _verify.py                           ─ 검증 스크립트 (재실행 가능)
```

## 한 줄 요약

```
응답자 ─→ index.html?type=tech|policy ─POST→ Apps Script Web App ─→ Google Sheet
```

URL 파라미터(`?type=...`)가 없으면 응답 자체가 차단되는 게이트 화면 → 분야 혼동 데이터가 시트에 쌓이지 않음.

## 설문 구조 (v2 · 2026-05-28)

5문항 · 약 5분 소요

| # | 문항 | 형식 |
|---|---|---|
| 0 | 개인정보 수집·이용 동의 | 라디오 (필수) |
| 1 | 참석자 개인 정보 | 성명 · 연락처 · 이메일 |
| 2 | 워크숍 참석 여부 | 라디오 (참석 / 불참) |
| 3 | 이해도 3문항 | 3점 척도 (그렇지 않다 / 보통이다 / 그렇다) |
| 4 | 검증 방법 | 체크박스 카드 복수 선택 + 기타 입력 + 주관식 |

분야별 4-1 옵션 수: 기술 6개 / 정책 8개 (매뉴얼 예시 그대로 옵션화)

## 배포 절차 (요약)

1. Google 스프레드시트 생성 → ID 복사
2. Apps Script 새 프로젝트 → `apps_script_backend.gs` 붙여넣기 → `SHEET_ID` 교체 → 웹 앱 배포 → URL 복사
3. `index.html` 안의 `APPS_SCRIPT_ENDPOINT` 에 URL 붙여넣기
4. `index.html` 을 Vercel / GitHub Pages 에 업로드
5. 분야별 URL 2개 확정 (`?type=tech` / `?type=policy`, 단축 없이 원본 사용)
6. 자체 테스트 1건 → 발송 안내문 템플릿 이용해 발송

상세 절차는 `사전설문_배포가이드_2026-05-28.txt` 또는 `빠른배포_1페이지_체크리스트.txt` 참조.

## Apps Script 운영 보조 함수

`apps_script_backend.gs` 하단에 다음 3개 함수가 포함되어 있습니다.
Apps Script 편집기에서 함수명을 선택하고 ▶ 실행하면 동작합니다.

| 함수 | 역할 |
|---|---|
| `runSetup()` | 시트 헤더 자동 생성 + 권한 부여 확인 (최초 1회) |
| `deleteTestRows()` | '테스트' 로 시작하는 성명 또는 example 메일을 가진 행 일괄 삭제 |
| `printSummary()` | 분야별 응답 수, 참석률, 척도 분포, 검증 방법 선호도 콘솔 출력 |
| `backupResponses()` | 응답 시트를 `응답_백업_YYYYMMDD_HHmm` 시트로 복제 |

## 자가검증 (운영자 검증 시 활용)

배포 직전 `_audit/` 폴더의 검증 리포트 두 건을 확인해 주십시오.

| 리포트 | 내용 | 결과 |
|---|---|---|
| `피드백반영_검증리포트.txt` | 피드백 7건 각각의 적용 증거 | **7/7 자동 점검 통과** |
| `문항일치_검증리포트.txt` | docx 원문 핵심 문구 25개의 HTML 존재 여부 | **25/25 매칭 + 의도적 변경 8건 명시** |

다시 검증하려면 `_audit/` 폴더에서 다음 명령으로 재실행 가능합니다.

```bash
python _verify.py
```
