────────────────────────────────────────────────────────────────
  STEP 1.  Google 스프레드시트 만들기                    [ 2분 ]
────────────────────────────────────────────────────────────────
   □ drive.google.com 접속 → 새로 만들기 → Google 스프레드시트
   □ 파일명 변경  ([2026 TOP100 Summit] 사전설문 응답)
   □ 주소창 URL 에서 /d/ 와 /edit 사이 문자열 복사
        → 이것이 SHEET_ID


────────────────────────────────────────────────────────────────
  STEP 2.  Apps Script 백엔드 배포                       [ 7분 ]
────────────────────────────────────────────────────────────────
   □ script.google.com 접속 → 새 프로젝트
   □ 기본 코드 모두 지우고 apps_script_backend.gs 내용 붙여넣기
   □ const SHEET_ID = '여기에 1번에서 복사한 ID 붙여넣기'
   □ (선택) const ADMIN_EMAIL = 'gpt@rnbdp.com'  ← 알림 받을 메일
   □ Ctrl+S 저장
   □ 함수 선택 runSetup → ▶ 실행 → 권한 동의
        → '시트 응답, 행 1' 로그 나오면 성공
   □ 배포 → 새 배포
        유형 : 웹 앱
        실행 : 나
        액세스 : 모든 사용자
        → 배포 클릭 → 웹 앱 URL 복사


────────────────────────────────────────────────────────────────
  STEP 3.  index.html 에 URL 연결                       [ 1분 ]
────────────────────────────────────────────────────────────────
   □ 메모장으로 index.html 열기
   □ Ctrl+F → __APPS_SCRIPT_URL__ 검색
   □ 그 자리에 2번에서 복사한 URL 붙여넣기 (따옴표 안 글자만)
   □ 저장


────────────────────────────────────────────────────────────────
  STEP 4.  HTML 호스팅                                   [ 5분 ]
────────────────────────────────────────────────────────────────
   ─ Vercel (가장 빠름)
        □ vercel.com 가입 → Add New → Project → 메인화면에
          index.html 을 드래그 → 자동 도메인 발급

   또는 GitHub Pages
        □ 저장소 생성(Public) → index.html 업로드
        □ Settings → Pages → main 브랜치 Save


────────────────────────────────────────────────────────────────
  STEP 5.  분야별 발송 URL 확정                          [ 1분 ]
────────────────────────────────────────────────────────────────
   □ 기술 분야    https://moduidea-survey.vercel.app/?type=tech
   □ 정책 분야    https://moduidea-survey.vercel.app/?type=policy
   □ 두 URL을 직접 클릭해 분야별 화면(헤더 배지)이 뜨는지 확인

   ※ 운영 결정: 단축 URL 사용 안 함 (원본 URL 그대로 발송)


────────────────────────────────────────────────────────────────
  STEP 6.  실 발송 전 자체 테스트 (테스트 응답 1건 입력)  [ 3분 ]
────────────────────────────────────────────────────────────────
   □ 기술 URL 접속 → 동의 → 본인 정보 → 참석 → 5점 척도
     → 검증 방법 1개 선택 → 4-2 한 줄 작성 → 제출
   □ '제출이 완료되었습니다' 팝업 확인
   □ 스프레드시트에 새 행이 추가됐는지 확인
   □ C열 '분야' 값이 '기술 분야 (Technology)' 인지 확인
   □ 정책 URL도 동일하게 1건 테스트
   □ 테스트 행 2개를 스프레드시트에서 삭제

   ※ Apps Script 편집기에서 deleteTestRows() 실행으로 자동 삭제도 가능
     (헬퍼 함수 — apps_script_backend.gs 하단 참조)


────────────────────────────────────────────────────────────────
  STEP 7.  실 발송                                       [ 1분 / 1명 ]
────────────────────────────────────────────────────────────────
   □ 발송_안내문_기술분야.txt 내용 그대로 복사 → 기술 분야 40명 발송
   □ 발송_안내문_정책분야.txt 내용 그대로 복사 → 정책 분야 60명 발송
   □ ○○○ 자리에 수신자 성함 채우기
